## 3. 电机 ID 与 URDF 关节映射

| 电机 ID | 功能 | 驱动的 URDF 主关节 | 远端关节 |
|---:|---|---|---|
| ID1 | 拇指屈伸 | `thumb_joint_2` | 无 mimic |
| ID2 | 食指屈伸 | `index_joint_1` | `index_joint_2` 跟随 |
| ID3 | 中指屈伸 | `middle_joint_1` | `middle_joint_2` 跟随 |
| ID4 | 无名指屈伸 | `ring_joint_1` | `ring_joint_2` 跟随 |
| ID5 | 小指屈伸 | `little_joint_1` | `little_joint_2` 跟随 |
| ID6 | 拇指内旋/侧摆 | `thumb_joint_1` | 无 mimic |

ID2～ID5 的 URDF 约束均为：

```text
远端关节角 = 主关节角 × 1.0 + 0
```

这表示 ID2～ID5 的第二关节不能被单独控制。电机只驱动主关节，第二关节由机械欠驱结构/URDF mimic 关系跟随。

## 4. 位置值和角度映射

### 4.1 通用定义

- 电机位置值记为 `p`，范围为 `0～2000`。
- `p` 是控制器使用的整数位置值，不是角度单位。
- 位置值原样发送给当前控制器。
- 当前采用线性映射，后续可以用实测数据替换为分段线性映射。
- 角度在 URDF 和本文件中使用弧度；括号内给出角度制便于理解。
- 以下姿态描述假设灵巧手竖直立在桌面上。

### 4.2 各电机映射

| ID | 位置到角度 | 端点姿态 | 方向 |
|---:|---|---|---|
| ID1 | `thumb_joint_2 = π/2 - (π/4) × p/2000` | `p=0`：相对水平面 90°；`p=2000`：相对水平面 45° | 位置值增大，关节角减小 |
| ID2 | `index_joint_1 = (π/2) × p/2000` | `p=0`：水平 0°；`p=2000`：竖直 90° | 位置值增大，关节角增大 |
| ID3 | `middle_joint_1 = (π/2) × p/2000` | `p=0`：水平 0°；`p=2000`：竖直 90° | 位置值增大，关节角增大 |
| ID4 | `ring_joint_1 = (π/2) × p/2000` | `p=0`：水平 0°；`p=2000`：竖直 90° | 位置值增大，关节角增大 |
| ID5 | `little_joint_1 = (π/2) × p/2000` | `p=0`：水平 0°；`p=2000`：竖直 90° | 位置值增大，关节角增大 |
| ID6 | `thumb_joint_1 = (2π/3) × p/2000` | `p=0`：与手掌平行；`p=2000`：相对手掌转动 120° | 位置值增大，拇指内旋角增大 |

### 4.3 张开、闭合和复位语义

| 项目 | ID1 | ID2～ID5 | ID6 |
|---|---:|---:|---:|
| 软件定义的张开位置 | `p=2000` | `p=2000` | `p=0`（拇指向外/与掌面平行） |
| 主要闭合方向 | 向 `p=0` | 向 `p=0` | 不使用屈伸式闭合语义 |
| 当前统一全开姿态 | 2000 | 2000 | 0 |

当前控制器的历史复位动作不是完全等同于上述全开姿态：

```text
controller_reset_pose = [1000, 2000, 2000, 2000, 2000, 0]
```

其中 ID1 会先单独发送 `p=1000`，随后广播同一组复位值。这个历史行为暂时保留，不在本阶段修改控制器。

## 5. URDF 关节限制

当前 URDF 中的几何关节范围如下。`effort="0"` 和 `velocity="0"` 是模型文件中的占位值，不能解释为电机额定力或额定速度。

| URDF 关节 | 下限 | 上限 | 约等于角度范围 | mimic |
|---|---:|---:|---:|---|
| `thumb_joint_1` | 0 | 2.0943951024 | 0°～120° | 无 |
| `thumb_joint_2` | 0 | 1.5708 | 0°～90° | 无 |
| `index_joint_1` / `index_joint_2` | 0 | 1.5708 | 0°～90° | `index_joint_2` 跟随 `index_joint_1` |
| `middle_joint_1` / `middle_joint_2` | 0 | 1.5708 | 0°～90° | `middle_joint_2` 跟随 `middle_joint_1` |
| `ring_joint_1` / `ring_joint_2` | 0 | 1.5708 | 0°～90° | `ring_joint_2` 跟随 `ring_joint_1` |
| `little_joint_1` / `little_joint_2` | 0 | 1.5708 | 0°～90° | `little_joint_2` 跟随 `little_joint_1` |

真实机械限位、零位误差、回程间隙和传动比仍需实物测量。

## 6. 串口控制协议

### 6.1 串口参数

| 项目 | 值 |
|---|---|
| 波特率 | `921600` |
| 读超时 | `20 ms` |
| 写超时 | `20 ms` |
| 多字节字节序 | 小端序（little-endian） |
| 帧头 | `0x55 0xAA` |
| 校验 | `sum(data[2:]) & 0xFF` |

校验从长度字段开始累加，不包含两个帧头字节。

### 6.2 单电机位置指令

单电机指令的主要字段为：

```text
帧头 | 长度 | 电机 ID | 命令 0x32 | 参数区 | 力 | 速度 | 位置 | 校验和
```

已确认的协议示例（ID2、力 3500、速度 1000、位置 1100）：

```text
55 AA 0D 02 32 25 00 05 00 00 00 AC 0D E8 03 4C 04 5F
```

其中：

- `02`：电机 ID2。
- `32`：单电机设置命令。
- `AC 0D`：力参数 3500，小端序。
- `E8 03`：速度参数 1000，小端序。
- `4C 04`：目标位置 1100，小端序。
- `5F`：校验和。

### 6.3 广播位置指令

广播地址为 `0xFF`，广播命令为 `0xF2`。每组电机数据为：

```text
电机 ID | 16 位位置值
```

已确认的示例：

```text
位置 [ID1..ID6] = [800, 2000, 2000, 2000, 2000, 1600]
55 AA 13 FF F2 01 20 03 02 D0 07 03 D0 07 04 D0 07 05 D0 07 06 40 06 DE
```

长度字段为 `1 + 6×3 = 19 = 0x13`。

### 6.4 力反馈读取

读取 ID2 的请求示例：

```text
55 AA 03 02 30 00 00 35
```

当前代码读取 19 字节响应，要求响应头为 `AA 55`，并将 `response[13:15]` 按小端有符号 16 位整数解析为力反馈值。响应的其他字段尚未在仓库中定义。

当前没有实际位置查询帧，因此 `motor_current_pos` 只是最近一次发送的目标值，不是编码器实际位置。

## 7. 现有 8 类抓取动作库

动作执行分为两步：

1. 在空中广播预塑形位置，等待约 `1.5 s`。
2. 到达抓取位置后，按动作库逐个发送闭合指令。

当前 `scripts/hand_bridge.py` 中 8 类闭合指令统一使用 `force=4000`、`speed=1000`。这些是当前软件动作参数，不是电机额定最大力/速度。

| Type | 名称 | 预塑形广播 `[ID1..ID6]` | 闭合目标位置 |
|---:|---|---|---|
| 1 | Tip Pinch | `[800,2000,2000,2000,2000,1600]` | ID1=300，ID2=1100 |
| 2 | Ring | `[800,2000,2000,2000,2000,1800]` | ID1=300，ID2=1100，ID3=900 |
| 3 | Prismatic 3-Finger / Quadpod | `[800,2000,2000,2000,2000,1800]` | ID1=300，ID2=1100，ID3=900，ID4=1100 |
| 4 | Large Diameter | `[800,2000,2000,2000,2000,2000]` | ID1=300，ID2=1100，ID3=900，ID4=1100，ID5=1100 |
| 5 | Medium Wrap | `[800,2000,2000,2000,2000,1200]` | ID1～ID5 全部=300 |
| 6 | Tripod | `[800,2000,2000,2000,2000,100]` | ID1=300，ID2=1800，ID3=300，ID4=300，ID5=300 |
| 7 | Sphere 3-Finger | `[800,2000,2000,2000,2000,300]` | ID1=300，ID2=1100，ID3=900 |
| 8 | Distal Type | `[800,2000,2000,2000,2000,2000]` | ID1=400，ID3=900，ID4=1100 |

注意：动作库的“闭合电机列表”是控制策略，不等同于接触定义。例如 Type 6 的代码会发送 ID4、ID5 的辅助动作；是否实际接触物体由几何和物体尺寸决定。

## 8. 速度、力和位置参数边界

当前仓库没有记录电机的额定最大速度、额定电流、额定力矩或安全力上限。下面是软件实际使用值，不是硬件规格：

| 控制路径 | 电机 | 力参数 | 速度参数 | 位置参数 |
|---|---|---:|---:|---|
| `scripts/hand_bridge.py` 八类闭合动作 | ID1～ID5 | 4000 | 1000 | 由对应 Type 的 `close` 列表给出 |
| `scripts/hand_bridge.py` 预塑形广播 | ID1～ID6 | 不发送独立力/速度字段 | 不发送独立力/速度字段 | 广播位置数组 |
| `controller_ub.py` 旧版 `action_*` 动作 | 通常 ID1～ID5 | 2500 | 1000 | 旧版动作内部定义 |
| `controller_ub.py` 复位 | ID1 | 4000 | 2000 | 1000 |
| `controller_ub.py` 复位 | ID2～ID5 | 1500 | 2000 | 2000 |
| `controller_ub.py` 复位广播 | ID1～ID6 | 广播不带独立力/速度 | 广播不带独立力/速度 | `[1000,2000,2000,2000,2000,0]` |
| 当前 ID6 动作 | ID6 | 未使用独立力参数 | 未使用独立速度参数 | 只通过广播位置控制 |

本阶段保持上述软件值不变。必须取得电机数据手册或通过受控实验确认额定上限后，才能增加限幅、过流保护或基于力反馈的自动停止。
