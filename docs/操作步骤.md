# AnyDexGrasp 眼在手上 (Eye-in-Hand) 操作步骤

**当前方案**: D435i 相机安装在 Z1 末端，`anydex_eih_grasp.py` 统一编排 Z1 运动和抓取执行。

## 硬件准备
- Unitree Z1 机械臂上电
- RealSense D435i 安装在 Z1 末端
- 自研五指欠驱灵巧手安装在 Z1 末端
- 工作台面清理，放置待抓取物体

## 操作流程

### 终端0：启动 Z1 底层控制器
```bash
ping 192.168.123.110
cd /home/jonas/Projects/unitree_z1/Unitree-Z1_SDK/z1_controller/build
./z1_ctrl
```

### 终端1：启动 RealSense 相机
```bash
conda activate anydex
cd ~/Projects/AnyDexGrasp_ws/scripts
python realsense.py
```

### 终端A：启动抓取编排器（常驻，不要关）
```bash
conda activate anydex
cd ~/Projects/AnyDexGrasp_ws/scripts
python anydex_eih_grasp.py
```
内部流程: MoveJ 到准备点 → MoveJ 到观测位姿 → 等待用户拍照

### 终端B：拍照推理
```bash
conda activate anydex
cd ~/Projects/AnyDexGrasp_ws/scripts
python run_inspire_preview.py --visualize --collision --preprocess \
    --min_depth 0.2 --max_depth 0.6 \
    --inspire_mesh_json_path /home/jonas/Projects/AnyDexGrasp/generate_mesh_and_pointcloud/inspire_urdf
```
Open3D 窗口弹出后检查抓取姿态（绿/橙法兰框 + 蓝色指尖球），确认无误。

### 终端A（续）：确认抓取
- 按**回车**：自动执行闭环抓取——取命令观测位姿 → 坐标变换 → MoveJ 接近（IK 不可达自动降接近高度 12→8→6cm 重试，全失败优雅回零中止）→ 空中张手+预塑形 → 可打断下降（**Space/Esc 暂停接管人工微调**，Ctrl+C 中断回零）→ 抓取点逐指闭合 → **[回车确认抓取]** → 上提 → 丢弃位姿 → **[回车确认丢弃]** → 松手 → 3s 后自动回零（`--no-hand` 时抓取点会暂停等手动确认）
- 按 **Ctrl+C**：先回零再安全退出，不掉力，机械臂停在零位不半空下垂

### 终端C（可选）：自研手控制
```bash
cd ~/Projects/AnyDexGrasp_ws/hand_control
python gui_ub.py
```

## 架构
```
终端A: anydex_eih_grasp.py (编排器)
         └─ subprocess → MoveZ1.py --server (Z1驱动, /usr/bin/python3.8)
终端B: run_inspire_preview.py (纯视觉, conda anydex)
         └─ import → robot_inspire.py (网络推理 + 碰撞检测)
```

## 已知问题
1. 穿模 — `--collision` 默认开启，偶尔可能滤掉所有候选
2. 桌面误识别 — 可加 `--preprocess` 启用 RANSAC 桌面分割；或调整 `--min_depth`/`--max_depth`
3. 高物体点云效果差
4. workspace 滤波已统一为 ±0.40，可通过 `--grasp_ws_x_range`/`--grasp_ws_y_range` 调整
5. ⚠️ `--preprocess` 会把桌面从点云和碰撞检测中一并滤除，无指尖/掌心防穿桌检查（只剩 MoveZ1 法兰 z≥0.12 兜底）——空载接近时留意指尖高度；下降过程可按 **Space/Esc** 暂停接管人工微调避免碰撞
6. `mount_yaw_deg=-90°` 修正后网络朝向偏差可低至 9.1°（实测），会采用网络朝向——预览绿色法兰框=将采用网络朝向、橙色=回退固定朝向；偏差超过 config `orient_deviation_thresh_deg`（当前 90°）时回退固定朝向。指尖水平落点偏差用 config `offset_xyz`（基座系 +X/+Y 偏移）修正，不改变 z
7. ⚠️ 已知系统偏移（已用 `verify_z1_pose.py` 定位）：`getpose` 与命令位姿差 39.4±1.0mm，恒定沿接近轴。cam→base 已改用命令观测位姿（切换后目标上抬 ~35mm，部分抓取 IK 不可达，**切换评估中**）。键盘点动以命令目标为基准，不受影响
